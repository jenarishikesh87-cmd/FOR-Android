# Install the current FOR website now

The current Cloudflare Pages build is already a PWA. From Android Chrome:

1. Open your working base URL: `https://for-workout-log.pages.dev/`.
2. Open Chrome's three-dot menu and tap **Install app** or **Add to Home screen**.
3. Launch the FOR icon from your home screen. Keep using this version until the native APK has been built and tested.

The native Android source in this kit is a separate next step; it does not automatically update the live website.
